# ---------------------------------------------------------------------------
# Loris — Python requirements   (pip install -r requirements.txt)
#
# This file is self-contained on purpose: the entire Python binding toolchain
# comes from pip so the build reproduces off-platform with just a C++ compiler
# and this venv — no Homebrew/apt required.
#
#   setuptools : build-time. Restores the `distutils` shim that ./configure's
#                Python-header probe needs on Python 3.12+ (3.12 removed distutils
#                from the stdlib).
#   swig       : the wrapper generator that produces scripting/loris_python_wrap.C
#                and loris.py. Pinned to the tested version for reproducible output.
#
# The Loris *runtime* module (`import loris`) has NO third-party Python
# dependencies of its own — it is a self-contained C extension.
#
# Optional system libraries (NOT pip-installable; auto-detected by ./configure):
#   FFTW3    - faster non-power-of-two DFTs. Without it, Loris uses its bundled
#              DFT (src/fftsg.c) and builds/works fine. Install if you want it:
#              macOS: brew install fftw   |   Debian/Ubuntu: apt install libfftw3-dev
#   automake - only needed to regenerate ./configure (autoreconf). Use >=1.16 for
#              a Python-3.12-safe config/py-compile.
# ---------------------------------------------------------------------------
